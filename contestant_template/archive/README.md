# archive —— 旧场景的示例，不能直接跑

这里面的示例是给**旧场景 `fire_drill_room`** 写的，坐标系跟现在的样题场景
`sample_room` **不一样**：

| | 原点 | 坐标范围 |
|---|---|---|
| `fire_drill_room`（旧） | 房间**中心** | 有正有负，比如 `(7.0, -9.5)`、`(-4.5, 7.0)` |
| `sample_room`（现在） | 房间**西南角** | 全是正数，`x∈[0,20]`、`y∈[0,25]` |

所以直接拿来跑，飞机会往场外或者障碍里飞。而且 `docker-compose.yml` 的默认
世界现在是 `sample_room`，启动脚本也不再传 `WORLD_ENV`——等于这些示例的航点
跟实际加载的场景对不上。

**要看当前能跑的完整例子，去上一层的 `*_lite.py`，或者 `../normal/`。**

留着这些文件是因为有几处写法仍有参考价值：

- `地面火情搜索示例.py` —— 边飞边找的扫描航线生成
- `高楼火情绕飞版示例.py` —— 绕着立柱飞一圈找贴面标识（赛项 2026-09-23 改了
  部署方式之后不再需要绕飞，但绕飞航线本身的生成逻辑还能看）
- `高层火情巡检版示例.py` —— "三角形边中点定点巡检"的取点思路
- `舵机声光示例.py` —— 舵机和声光的最小用法
- `仿地飞行示例.py` —— 仿地模块上方的定高飞行

`_repro_return.py` 是一个返航问题的复现脚本，它 `import 高楼火情绕飞版示例`，
所以跟着一起放这儿。
