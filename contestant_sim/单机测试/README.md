# 单机测试程序

五个**单机**专项测试，用来在跑完整任务之前把各个能力分别验一遍。
出问题时范围小、好定位；全跑通了再上 `formation_lite` 等双机程序。

| 程序 | 测什么 | 起飞点 |
|---|---|---|
| `t1_抓取.py` | 物资点精降 + 抓取 | 任意（会先飞到物资点） |
| `t2_地面火情.py` | 地面火情精确瞄准（下视） | G 点 |
| `t3_高层火情.py` | 高层火情拍摄 + 精确对准（前视） | M 点或 N 点 |
| `t4_避障.py` | A↔B 往返避障 | A 点 |
| `t5_仿地.py` | G↔D 往返仿地 | G 点 |

坐标全部来自上一级的 `venue.py`，改场地只改那一个文件。

## 两边同一份

这五个程序在 `contestant_sim/单机测试/` 和 `contestant_real/单机测试/` 下
**逐字节相同**，坐标各取各自目录上一级的 `venue.py`。`run_real.sh` 的代码
漂移检查会比对这个子目录，改了一边不同步会被拦下。

**先在仿真里跑通，再上真机**：

```bash
cd ../../contestant_sim && ./run_test.sh t4   # 仿真
cd ../contestant_real   && ./run_test.sh t4   # 真机
```

仿真能验代码逻辑、规划器走不走通、声光链路；验不了定位漂移、落点精度、
降落上锁这些真机特性。

## 怎么跑

```bash
../run_test.sh t1          # 默认 NX02（任务机，带夹爪）
../run_test.sh t2 --nx01   # 指定用 NX01
../run_test.sh t4 --keep   # 结束后保留容器看日志
```

## 共同约定

- 每个程序都**只用一架飞机**，不涉及双机协同、不等队友消息
- 每一步都有 `progress()` 文字回传 + 关键节点的声光播报
- 结尾一律 `return_home()` 回起飞点降落
- 失败不硬闯：对不准/抓不到就报出来、回家，不会反复撞

## ⚠ 跑之前

1. `../vision_real.sh up` 起机载视觉，`status` 确认话题齐
2. 遥控器在手、安全员就位
3. **起飞点原点锁定**后坐标才准（迁移清单 A4）
4. t1 要确认夹爪舵机已验（清单 G1/G3）；t3 要确认发射舵机
